# Private War Room panoramic locker presentation

Implemented on `feat/war-room-panorama`. Not deployed or merged. The separately approved public arena game boxes were released through PR #215; this branch does not change public pages or add game boards to the private room.

The canonical private team room is `hitmen-locker.html`. It now loads a scoped panorama adapter after the existing private controller and shell. The older `hitmen-team-locker.html` tools page and all My Stall controllers remain unchanged.

The jersey source is the exact existing `assets/hitmen-v3/locker-photo-master.webp` pink-and-black front/back image used by the private V3 room and My Stall. A CSS viewport and silhouette clip present its front jersey inside the panorama without generating or replacing the kit. The high-detail stall route continues using the original full double-jersey image, saved names/numbers, gear/customization controls and private reports. The public black/copper team412.webp jersey is not used by the new private adapter.

The adapter reads only already-rendered, authorized active-roster stall elements. It does not query Supabase, export private roster data, modify customizations, fetch the public roster snapshot or introduce an alternative identity list. Saved display names and numbers come from those existing rows. Only existing anchor destinations are reproduced; teammate previews rendered as non-links for players stay non-links. Management retains the current dossier destinations. Training camp remains in its existing separate section and historical players remain excluded by the original controller. Active-roster count follows authorized data rather than a hard-coded count.

Room scenery is the existing versioned empty panoramic environment; the private Hitmen/Elite Chel Media sign and private jerseys are independent layers. Search supports case/punctuation-insensitive displayed-name matching, keyboard results and a clear no-match state. Drag/swipe and native arrow-key viewer controls explore the room. Clicking an authorized jersey follows its existing private stall link; selecting a name also provides an explicit open-stall action. No account permissions or server/RLS policies were changed.

The view is inside the existing hidden private application container and is created only when the current controller grants access. Sign-out, membership denial, roster removal and account-change events destroy its viewer and clear copied names/links. Pending viewer initialization is invalidated with a generation token. If the viewer or artwork fails, the original full private stall grid remains usable below. No fixed data is substituted when private data is unavailable.

Validation: the extended `test-hitmen-locker-restoration.cjs` suite passed in headless Edge at 360, 390, 768 and 1440px with isolated auth/data fixtures. It covers exact private image reuse, active/TC separation, saved fields and profile destinations, search, 17 example active stalls, player own-stall restriction, no teammate dossier action, anonymous/wrong-team denial, no unauthorized private reads, sign-out clearing, existing jersey edits and report behavior, canonical/legacy bookmarks and page overflow. No real private session, production DB writes or actual player data were used. Example-only screenshots were visually inspected. Physical phones and screen-reader software were not exercised.

The existing CI workflow now includes the adapter paths and syntax check. The browser test accepts optional installed Playwright/Edge paths while retaining its previous defaults in CI. Public release #215 passed its own checks and was verified at the live public URL at desktop/phone widths using the real public games feed.
