# Player Card Studio release — November 8, 2026

Authorized scope: polish and publish the card builder; link player cards from
public team locker rooms and searched leaderboard rows. User artwork must not
appear publicly without review.

- Layered 1400×2000 preview and PNG share a single renderer. Nameplate now uses
  dark steel, a restrained finish accent, and a faded team mark.
- ECM beta OVR is an explicitly documented 60–99 product scale. The underlying
  0–100 weighted component index remains visible separately. Index 60 maps to
  OVR 83; this is display mapping, not evidence of calibrated hockey ability.
- Public CHL roster stalls open the selected player's builder directly by LG ID
  plus kind. Both searchable leaderboard pages and LG3s desk player rows have
  explicit View / Build Hockey Card links. Existing leaderboard profile actions
  remain. The builder links back to that player's public team room where known.
- Artwork previews stay on device unless explicitly submitted to private manager review. Approval is required for future shared display; the public artwork delivery path remains disabled. Existing private card collections still save metadata only.
- Eligible CHL beta ratings are automatic; LG3s automatic ratings remain pending.
  Earned XP/unlocks, cross-device artwork editing, payments and identity claims
  are not introduced by this release.

Validation: targeted rating/studio/workflow/leaderboard tests plus background
persistence checks and the 62-team roster fixture. Roster tests verify exact
card ID/kind links for all 1,037 main-roster players. Browser checks verified
Setty's public room → card, both searched CHL leaderboard links, the live
Supabase rating summary, and a PNG export with user-supplied character artwork.
No private Labs data is included. No production database mutation is required.

## Private artwork review and arena game centre

Management → Card Artwork Approval opens a hidden, noindex page. The server uses the existing trusted manager allowlist; hiding the link is not the access control. Signed-in players explicitly submit PNG artwork to a private bucket. Managers can approve/reject with recorded decisions, reject with a reason, and revoke an approval. Images cannot be overwritten; replacement needs a new review. Approval does not enable public artwork. No player ownership claim is inferred.

Supabase migration applied successfully.
