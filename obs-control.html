Your inputs. On screen.

Xbox-style controller display powered by Keymap. Add it as a separate Browser Source above gameplay, then resize and position it in OBS.

Playing on Xbox Series X? A controller connected only to your console cannot send inputs to this overlay. Live movement requires a controller visible to the streaming computer. A capture card carries video and audio, not controller inputs.

Open Overlay

OBS size: 600 × 400. Keep “Shutdown source when not visible” off. Press a controller button after OBS starts. Transparent needs no chroma key; green screen needs an OBS Chroma Key filter. Colour changes update the URL here; paste the new URL into OBS to apply them.

Input connection options and troubleshooting
  • PC gameplay: connect your controller to the streaming PC by USB or Bluetooth. Verify buttons and sticks in the standalone overlay, then in OBS. Browser and OBS detection can differ.
  • Console gameplay: keep your existing capture feed. For real input display, a compatible input forwarding bridge or hardware adapter must expose the same inputs to the PC. No bridge is included here; verify console and controller compatibility before choosing one.
  • Remote Play: a possible setup to investigate is a PC-connected controller driving a supported Xbox Remote Play client. This panel does not forward inputs or configure Remote Play; test the client, PC detection and OBS together before relying on it.
  • No suitable input path: use a camera aimed at your hands/controller as an OBS video source. The drawing alone is only a visual preview.
  • Preview blocked or blank: open the standalone overlay. Keymap is an external service and its availability, embedding policy and Gamepad API support can change. Try OBS “Refresh cache of current page”.

Settings are stored in the URL. This panel does not publish scene changes, pair with an Xbox, or relay input between devices. Keymap setup and measurement limits.
